Use the worksheet as the board. Keep each item's safe excerpt, evidence label, date, location, verdict, and limit together. An ordinary local file can be edited; a receipt is inspectable evidence, not a tamper-proof certificate. Use these labels:

- Live: you observed this new execution; record its real time.
- Saved learner run: an earlier actual run; record its original time, not today's screenshot time.
- Authored example: supplied or invented teaching output; no actual run is claimed.
- Not performed: the check has no result yet. Keep it visible.

Mixed boards are allowed. Label each item separately.

| # | Item | Minimum useful evidence |
| --- | --- | --- |
| 1 | Ownership | Your local project or fork, and a choice you can explain; hide account details |
| 2 | Before state | Exact input, actual miss, expectation, old receipt |
| 3 | Tested change | One changed rule or setting; same-input after result and verdict |
| 4 | Normal run | New execution or labeled saved result; expected and actual |
| 5 | Failure route | Missing fact, conflict, invalid signal, or attack; safe result or honest miss |
| 6 | Fence | Data/source/permission boundary and its limit; no secret values |
| 7 | Used stop or fallback | Action, observable result, time; paused receipt or opened saved packet |
| 8 | Cost and reflection | Calculation, source/date or example label, review time, limitation, next safe step |

A green server status cannot replace item 4. An exact-match leak count cannot replace reading the answers. A stop label without an action cannot replace item 7. A local receipt cannot prove an unobserved scheduled run, hosted deployment, or upload.

For the change, keep input and relevant settings stable. If more than one thing changed, say so and narrow the conclusion. A failed repair is useful evidence; it cannot be presented as an improvement. You may present a smaller outcome that does work and name the unresolved miss.

Screen check: reopen only the final worksheet, safe excerpts, and chosen source. Hide notifications. The instructor must be able to inspect the board without access to your private folders or accounts.
