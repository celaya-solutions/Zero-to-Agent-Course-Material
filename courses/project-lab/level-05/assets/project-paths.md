## Documents

Prepare: use [Level 1](../../level-01/student.md) and its [edit card](../../level-01/manual-edit.md). Run `uv run --frozen zta doctor documents`, then `uv run --frozen zta test documents`. Launch `uv run --frozen zta start documents` and open [the local document app](http://127.0.0.1:8501). Keep the earlier provider, model, and supplied binder; no automatic cloud switching.

Normal: ask the supported location question again. Expect the supplied public source and matching location; open the actual citation. Failure: ask for an exact project price absent from the binder. Expect missing information and human confirmation, not an invented number. Use the original question text from Level 1 for the repair comparison. An optional unseen question must still use public or synthetic material and have its expectation written first.

Fence: source-limited retrieval and the selected provider boundary. A local app may still send selected passages if a cloud provider was chosen. Do not claim offline execution without the separate observation from Level 3.

Stop: in the app's terminal press Ctrl+C, wait for the shell prompt, then refresh the local page and confirm the app no longer responds. Closing a browser tab alone is not stopping the server. A completed cloud request may already have been charged. Keep a safe observation and open the saved document packet as fallback.

## Watchman

Prepare: use [Level 2 preparation](../../level-02/preparation.md). Run `uv run --frozen zta doctor watchman`, then `uv run --frozen zta test watchman`. Keep the hosted workflow off for the local capstone route.

Normal: run `uv run --frozen zta start watchman`. It makes one local round and exits. The first local round may establish a baseline; run again to inspect no change with the same marked value. Receipts are in .zta/watchman/rounds.jsonl. A local alert file is not a GitHub issue.

Failure-route evidence: use the earlier controlled OPEN/PAUSED transition and quiet repeat, or the [saved three-run packet](../../level-02/assets/fallback-three-runs.md). State that a status transition is expected event handling, not a fetch error. For an actual fetch-failure claim, show a real earlier failed receipt; tests using fixtures prove code behavior only. Do not corrupt or reset live state for this presentation. The [footer edit](../../level-02/manual-edit.md) offers a local harmless-change test.

Fence: one marked signal and the never list. Local rehearsal has no network or issue writes. Hosted permissions are separate and broader than one local file.

Stop: observe the local command exit and open the saved packet; no recurring local process is installed. This does not disable a hosted workflow. If you own an already configured hosted watcher, use Level 2's stop steps: disable Project Lab Watchman, set WATCHMAN_ENABLED=false, cancel queued/active runs, wait for final states, and record them. Do not re-enable to stage a demonstration. Mark the hosted stop Not performed if you cannot inspect it.

## Local Model

Prepare: use [Level 3 preparation](../../level-03/preparation.md) and [command card](../../level-03/assets/command-card.md). Run `uv run --frozen zta doctor local-models`, then `uv run --frozen zta test local-models`. Your existing zta-desk model must already be created from your private rules.

Normal and failure: run `uv run --frozen zta check local-models`. Keep both new rows and their receipt. The fixed writing test should retain the 4 p.m. deadline and reply request; your one-rule edit asks for two sentences under 50 words. The missing-information test should give no invented price or confirmed date. Compare with your original two Before rows. If the model name is missing, follow the existing create command; keep your edited private Modelfile.

Fence: the fixed loopback endpoint and local base model. Connected local generation is not proof of disconnected execution. No new disconnection is needed for the final talk; use your separately labeled earlier observation for an offline claim.

Stop: wait for the command to finish, or press Ctrl+C if running. Use `ollama stop zta-desk:latest`, then `ollama ps` to check that this model is not loaded. This unloads that model, keeps its files, and does not stop the entire Ollama server or prevent future requests. Open the saved comparison if generation is unavailable. Never stop another person's shared service.

## Front Desk

Prepare: use [Level 4 preparation](../../level-04/preparation.md). Run `uv run --frozen zta doctor front-desk`, then `uv run --frozen zta test front-desk`. Launch `uv run --frozen zta start front-desk` and open [the local desk](http://127.0.0.1:8504). Keep its locked phase and source rule. Resume only your own paused desk for the intended test, then leave it paused afterward.

Normal and failure: select Five callers and Run selected set. Score C1's supported public answer and C2's missing-price response, while retaining all five rows. For attack claims use the same A1-A10 comparison from Level 4; do not invent an unused attack slot. If time allows a new locked attack run, keep all ten results and label it separately. The current app does not have a custom-prompt field.

Fence: locked requests omit the synthetic bait and old history; the app has no send or booking tool. Wording still may fail. Read the answer: zero exact-value matches does not mean every attack held.

Stop: click Pause desk, then attempt a set. Inspect its new paused receipt with zero rows. The setting persists. For a long run use `uv run --frozen zta pause front-desk` in a second terminal at the course root. An already-sent request may finish computing; the control withholds that reply and prevents the next request. End paused, press Ctrl+C in the app terminal, and record both actions.
