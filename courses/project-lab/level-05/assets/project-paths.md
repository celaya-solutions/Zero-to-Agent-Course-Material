# Four Level 5 Project Paths

## Documents

Fresh normal test: a supported question. Failure: missing or conflicting fact. Fence: exact citation and stop rule. Switch or fallback: close project or use saved binder run.

## Watchman

Fresh normal test: unchanged run. Failure: controlled value change or fetch failure. Fence: never list and narrow signal. Switch: disable workflow.

## Local model

Fresh normal test: named model job. Failure: missing price or checkable false claim. Fence: localhost and source check. Switch: exit runner and close any network door.

## Front desk

Fresh normal test: public question and message card. Failure: price, high-stakes, impersonation, or an unused attack from the card. Fence: one business, one binder, removed secret, draft-only permission, human action. Switch or fallback: pause the desk, revoke the class key, or open the saved caller route.
