# Level 5 Outage Presentation Packet

Use this when a live dependency is unavailable. It does not lower the proof standard.

## Required labels

- Last live verification date and time: ________________________________
- Dependency that is unavailable: ____________________________________
- This material is: [ ] Screenshot  [ ] Saved output  [ ] Printed log
- Exact live check that would be run: _________________________________

## Three-minute route

1. State the user and outcome.
2. Show the last verified normal receipt.
3. Show the failure or attack and the tested fix.
4. Open the source, log, local boundary, approval gate, or other fence.
5. Show the documented switch or fallback action.
6. State cost, what is not proved live today, and the next safe check.

Never call saved material live. Honest limits are part of passing.
