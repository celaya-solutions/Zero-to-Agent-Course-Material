## Manual steps

1. Open the matching earlier card. Write the observed miss or unmet need and one prediction in your private worksheet.
2. Preserve the before receipt. If missing, label it missing and use saved teaching evidence for analysis; do not fabricate it.
3. Make only that card's allowed edit. Keep prompts, sources, base model, endpoint, tests, control settings, and earlier evidence unchanged.
4. Run the card's exact retests. Record actual outputs even if they fail, truncate, or take too long.
5. State what improved, stayed the same, or got worse. Undo only your one change if needed; keep both attempts.
