## Three feedback scores

| Score | Works | Honest | Theirs |
| --- | --- | --- | --- |
| 1 | Claim lacks inspectable support | Labels, failures, or cost assumptions missing | Cannot explain choices or operate the fallback |
| 2 | Some routes supported; one clear gap | Names a limit but needs clearer evidence | Explains choice with prompts or help |
| 3 | Evidence supports the stated bounded claim | Labels, misses, costs, and limits explicit | Explains choices and controls own evidence/fallback |

Scores guide one revision. A score of 9 is not a substitute for the eight items or a reopened upload. For authored analysis, Works assesses whether the analysis matches the provided evidence; Theirs assesses the learner's decisions, not ownership of the supplied application. Keep personal build/run gates separately open.

## Project-specific checks

Documents: inspect the real source quote, not just a citation-shaped string. Missing price must not be invented. Selected cloud use is not local-only merely because the browser URL is local.

Watchman: baseline differs from no change. A status change is an expected event, not an outage. A local rehearsal receipt is not an actual hosted issue or daily schedule. Preserve state. The footer edit validates selective watching; do not call it an alert-bug fix.

Local Model: named rules are not new trained weights. The same normal and missing prompts can be fresh runs. Check both after answers. Keep failed style repairs visible. Unloading retains files and server availability.

Front Desk: do not reset locking to collect another Before. C1/C2 are already supported fixed caller tests; the app has no custom-prompt box. Read partial and cut-off replies. A paused zero-row receipt proves that attempt sent no model request; it does not undo previous computation.

## Common grading cases

A live run crashes on stage: keep the failure, open saved proof, explain next check. Do not fail presentation skill solely for a service outage.

A learner lacks all prior evidence: use the authored packet for analysis and record personal checks Not performed. Do not mark previous levels complete.

A repair gets worse: keep it and narrow the demonstrated claim, or undo that one change and show a new retest. Never manufacture an improved reply.

A worksheet points only to a private local path: return it for a safe excerpt that can be reviewed in the upload. Do not ask for private folder access.

Cost is unknown: accept a labeled provisional/hypothetical calculation and the exact missing source, not a fabricated current bill.

A learner opts out of public speech: accept recorded, partner-read, paper, or Spanish delivery with evidence control and the same timing/checklist. No public ranking.
