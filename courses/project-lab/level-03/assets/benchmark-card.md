# Local Model Benchmark Card

Run the same prompts on both approved models.

## Prompt 1: daily writing

Rewrite this message so it is firm, polite, and under 70 words:

    The shared workbench has been left covered with tools three days this week. Please clear it by 4 p.m. today so the evening class can use it. Reply when it is ready. Do not add a threat or invent a policy.

## Prompt 2: public fact

    Using only the supplied CSR public-source snapshot, state where the lab is based and what kind of systems it builds. Name the source heading. If the material is not supplied to you, say so.

Open the source yourself before scoring.

## Prompt 3: known arithmetic

Three classroom suppliers quote 84 dollars, 109 dollars, and 97 dollars before tax. The class buys the cheapest option. With an 8.25 percent training tax and no tip, what is the total? Show the arithmetic and round to cents.

Instructor answer: 84 × 1.0825 = 90.93 dollars.
