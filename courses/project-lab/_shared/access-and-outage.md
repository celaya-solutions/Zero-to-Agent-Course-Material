# Access and Outage Routes

Access is not part of the grade. Decisions and evidence are.

## Device routes

- Laptop: complete the core route and, when ready, the builder extension.
- Level 1 live build: your own Windows or Mac computer with completed preflight.
- Phone or tablet: read the lesson and evaluate saved examples; this does not count as a live custom-app build.
- Shared device: each learner predicts, decides, and records their own proof.
- Paper: use the saved run in the level assets and write the change you would make.

## Outage rule

The instructor decides the room route within five minutes. Do not spend a class fixing one account.

1. Use the live route if the needed service works.
2. Use the saved run if the service or account is blocked.
3. Use paper if the projector, network, or power is unavailable.
4. Grade the same decision trail. Mark live-only fields Not applicable: saved run.

## Helper stop rule

Ask what the learner expects. Point to one next step. Give the controls back. If the same block remains after two tries, move to the saved run and record the block for after class.
