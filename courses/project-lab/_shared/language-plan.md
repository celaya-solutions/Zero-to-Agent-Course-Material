# English-First Bilingual Release Plan

Spanish is required for the course. It will be released in controlled phases so a partial translation is never mistaken for a complete course.

## Phase 1: included now

- English source course is complete.
- Every learner lesson carries Spanish anchors, a Spanish safety stop, and a short Spanish summary of the three tasks.
- The landing page labels the current language state plainly.
- Shared safety, testing, and case-study cards include Spanish guidance.

## Phase 2: next content release

- Translate every student.md and worksheet.md.
- Review with an El Paso or Ciudad Juárez bilingual educator.
- Run the validator against aligned English and Spanish objectives and proof.
- Pilot one level before translating all remaining levels.

## Phase 3: after the learner pilot

- Translate instructor plans and answer-key guidance.
- Build Spanish 20-slide decks from the corrected learner language.
- Time a Spanish-first run. Do not assume English timing transfers.

## Translation rules

- Translate the meaning, not the word order.
- Keep product names, commands, paths, and error text exactly as shown by the tool.
- Use everyday border-region Spanish and define technical terms in the sentence where they appear.
- Never mark a file translated until a human reviewer has read the full file.
